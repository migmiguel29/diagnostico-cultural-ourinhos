# Diagnóstico Cultural de Ourinhos

Dashboard Streamlit para análise das pesquisas sobre infraestrutura escolar de leitura e iniciativas culturais em Ourinhos (SP).

Inclui dados minimizados de 31 respostas escolares e 7 iniciativas culturais, indicadores e mapas preparados para geocodificação TomTom.

**Situação:** coordenadas ainda não levantadas. Nenhuma chave de API ou planilha bruta deve ser publicada.

Documentação e arquivos do projeto serão integrados neste repositório.
